# ADR 0006: UI texts in one catalog per language, chosen at build time

- Status: accepted
- Date: 2026-11-27

## Context

The UI texts were German literals spread over templates, services, date formatting and config
defaults. Translating the dashboard meant editing code in many places, and nothing told whether a
text had been forgotten. The display shows one language for its whole life; switching languages at
runtime (per request, per user) is not needed.

## Decision

- **One TOML file per language**, `src/home_dashboard/locales/<code>.toml`, read with the standard
  library (`tomllib`). Sections group the texts per widget; placeholders use `str.format` syntax
  (`"los in {minutes} min"`). Weekday and month names are lists, date formats are patterns
  (`"{weekday}, {day}. {month_name} {year}"`), so a language needs no code.
- `de.toml` holds the original German texts and is the reference; `en.toml` mainly proves that the
  mechanism works and serves as a starting point for translators. A test checks that every catalog
  has the same keys and placeholders as `de.toml`.
- **No gettext/Babel**: about a hundred short texts, a single plural case (handled with two keys),
  times in 24 h everywhere. An extract/compile step and a dependency would cost more than they save.
- A `Translator` (`i18n.py`) is created in the composition root and injected into the services and
  the templates, like the `Clock`; tests can render any language in-process.
- **The language is fixed when the image is built**: `docker build --build-arg LANGUAGE=en`. The
  image contains only that catalog and sets `HOME_DASHBOARD_LANGUAGE`; outside Docker the variable
  selects the language (default `de`).
- **The CLI (`check-config`, `find-stop`) is English only**: it is a tool for whoever sets up the
  dashboard, not part of the display.

## Consequences

- Adding a language is copying a TOML file and translating its values; the catalog test lists what
  is missing.
- Changing a text means changing it in every catalog (rule in AGENTS.md, enforced for keys and
  placeholders by the test, not for the meaning).
- Data from the sources is not translated: event titles, stop names, destinations, and the
  birthdays parsing rules, which match the texts a German contacts sync writes.
- A container cannot switch language without a rebuild; asking for a language it does not contain
  fails at startup with the list of available ones.
